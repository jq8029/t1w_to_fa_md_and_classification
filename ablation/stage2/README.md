# Ablation - Stage 2
This directory contains ablation experiments based on the Stage 2 implementation. The code is a standalone variant of `stage2/`. 

Please update file and path options in 'config.py' before execution.

## How to Run
The naming and number of the ablation settings correspond exactly to the Stage 2 ablation experiments reported in the paper.

- **Table 5. Multi-Modality Mode**  
python b0_binary_multi_modality.py

- **Table 6. Single-Modality Mode**  
python b0_binary_single_modality.py

- **Table 10. Multi-Modality Mode**  
python a0_3class_multi_modality.py

- **Table 11. Single-Modality Mode**  
python a1_3class_single_modality.py
